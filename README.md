# Vila Emes — Hotel Website

Marketing website for **Vila Emes**, a small seaside hotel in Plazh, Durrës, Albania. Statically generated and deployed on Cloudflare Pages.

**Live:** https://www.vilaemes.com

It's a marketing site, not a booking engine — every booking call-to-action links out to Booking.com.

## Tech

Astro 6 · Tailwind CSS v4 · TypeScript (strict) · four-locale routing (EN / AL / IT / DE) · no client-side framework. Hosted on Cloudflare Pages.
